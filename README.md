# CareFlow: Clinical Pathway Process Mining

## Project Overview
CareFlow explores hospital patient journeys using process mining
to identify workflow variations and potential waiting-time bottlenecks.

## Week 1 Objectives
- Generate fictional hospital event logs using Python.
- Simulate patient activities and operational inefficiencies.
- Export event data to CSV.
- Inspect data quality and prepare for later process mining.

## Project Structure
- `main.py` - Python event simulator
- `Data/` - Dataset files and documentation
- `Notebook/` - Exploratory analysis
- `Reports/` - Project reports
- `Visuals/` - Charts and diagrams
